Dasar Privasi JazAds

Versi: 20 Oktober 2026.

Pengendali: Mohamad Husaini Mohd Johaimis

E-mel privasi dan sokongan: mohamadhusaini37@gmail.com

Dasar ini berkuat kuasa apabila halaman ini diterbitkan.

Tujuan

JazAds ialah ruang kerja peribadi pemilik untuk menyediakan draf iklan, menyimpan rujukan akaun dan aset, serta menyemak akses Meta. Simpanan draf berasingan daripada penghantaran atau pengaktifan iklan. Operasi Meta memerlukan kebenaran khusus.

Data yang diproses

JazAds memproses maklumat akaun dan sesi pemilik; ID dan nama akaun iklan, Facebook Page serta pixel; permission sambungan dan token Meta; pautan serta fakta produk; teks, headline, sasaran dan bajet draf; fail video pilihan; serta ID objek, keputusan penghantaran dan log diagnostik. Token Meta disimpan secara disulitkan di pelayan. Diagnostik tidak sepatutnya mengandungi token atau App Secret.

Penggunaan data

Data digunakan untuk log masuk, menyimpan dan memulihkan draf, memaparkan pilihan aset, menyemak akses serta merekod hasil penghantaran supaya objek tidak berganda. Data yang diperlukan dihantar kepada Meta hanya bagi operasi yang diluluskan pemilik. Memilih ID pixel tidak memasang pixel pada laman web. Nama rujukan JazAds tidak menamakan semula aset Meta.

Simpanan dan penyedia perkhidmatan

Data aplikasi dan log masuk menggunakan Neon. Draf serta fail tertentu boleh disimpan dalam pelayar. Versi semasa turut menggunakan Mac pengendali untuk pelayan dan fail video, serta Cloudflare untuk trafik HTTPS sementara. Versi aplikasi Netlify masih tersedia. Halaman dasar privasi dan arahan pemadaman ini dihoskan melalui GitHub Pages apabila diterbitkan di sana. GitHub memproses trafik halaman dan merekod alamat IP pelawat bagi tujuan keselamatan, termasuk pelawat yang tidak log masuk. Dua halaman ini tidak menerima token Meta atau data draf aplikasi. Pautan produk dihantar kepada laman web berkenaan apabila kandungannya dibaca. Operasi Meta melibatkan pemprosesan oleh Meta.

Tempoh simpanan dan pembersihan manual

  • Draf, produk dan tetapan tersimpan: disimpan selagi diperlukan pemilik, sehingga dipadam atau permintaan pemadaman diselesaikan. Tiada pemadaman automatik mengikut umur rekod.
  • Salinan video persediaan pada pelayan: sasaran pembersihan manual dalam 30 hari selepas ujian atau proses selesai atau dibatalkan, setelah disahkan tidak diperlukan oleh draf atau proses lain. Fail asal pada peranti dan video dalam Meta tidak termasuk dalam pembersihan ini.
  • Log diagnostik: semakan dan pembersihan manual selepas 90 hari. ID objek dan keputusan penghantaran yang masih diperlukan untuk semakan atau pencegahan pendua dikekalkan berasingan sehingga tidak lagi diperlukan atau dipadam secara terkawal.
  • Token sambungan: disimpan sehingga sambungan dibuang daripada JazAds atau permintaan pemadaman yang berkaitan diselesaikan. Tamat tempoh token tidak bermaksud rekod token dipadam secara automatik.

Tiada penjadual pembersihan automatik bagi tempoh di atas. Tempoh sandaran dan pemadaman di pihak penyedia belum disahkan; dokumen ini tidak menjanjikan pemadaman sandaran pada tarikh tertentu.
